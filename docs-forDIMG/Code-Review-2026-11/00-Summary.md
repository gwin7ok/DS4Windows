## 3. 全体の要約

DI の骨格は健全で、Service Locator も静的な窓口もほぼ残っていない。弱点は次の 4 つにまとまる。

1. **生成順・終了順が型で表れていない**（1-1、1-2）。配列の中身を別の型のコンストラクターが作る箇所と、破棄の順序を `App` の手書きの並びだけが守っている箇所がある。
2. **安全弁の抜け**（6-7）。全コントローラー共通のロックが `try`／`finally` で守られておらず、例外 1 つで全入力が止まり得る。
3. **「割り当て 0」が文書どおりに守られていない**（6-1、6-2、6-8、6-10、6-11）。検査するテストも、その経路を見ていない。ジャイロを持つ機種では、既定の設定でも毎フレーム割り当てが起きる。
   同じ「安全弁の抜け」は、画面側のタイマーにもある（6-12）。
4. **出力の種類と、左右スティックの画面は、足すときの手数が多い**（5-1、4-4）。入力機種の追加ほど道が整っていない。機種間の読み取りの重複（4-2）も、片方だけ直す事故のもとになる。
