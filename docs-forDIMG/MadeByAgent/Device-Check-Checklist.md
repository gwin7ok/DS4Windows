## 1. 起動と終了（Phase19・27・35）

  - 仮想パッドが消える／出力スロットとアプリの設定が保存される／プロセスが残らない／次の起動が正常。
- 疑う場所: `Composition/Startup/AppShutdownSequence`、`Composition/MainWindowFactory`、`Processing/Services/Connection/RuntimeBootstrapper`。

## 9c. 例外の型を限定した catch（PhaseRV2 S3）
想定外の例外は握りつぶされず上へ伝わる。次の操作で、クラッシュ（未処理の例外）やログの Error が出ないことを確かめる。
- [ ] 起動・終了を繰り返す（優先度の設定、キーボードの repeat 設定の読み込み、Logs・Macros・Profiles フォルダーの作成）。
- [ ] 設定の保存先が書き込めない場所（読み取り専用）でも、起動できる。
- [ ] メイン画面の「Profiles フォルダーを開く」、HidHide Client・XInputChecker の起動、ドライバー導入（失敗してもクラッシュしない）。
- [ ] 更新画面（UpdaterWindow）で、一時フォルダーの削除に失敗しても進む。
- [ ] Xbox の親デバイスを隠す機能のオン・オフ（記録ファイルの保存・削除）。
- [ ] CLI（IPC）のコマンド実行の結果が返る。
- 疑う場所: 例外フィルター `catch (Exception caught) when (caught is …)` の箇所（`git grep "caught is"`）。型を足すか、理由のコメントとともに広げる。

## 9d. 画面の操作をコマンドへ（PhaseRV3）
メイン画面・バージョン情報・自動プロファイル・割り当て編集の操作を、コマンド（`ICommand`）へ結び直した。XAML のバインディングの間違いは、実行するまで分からない（出力ウィンドウの BindingExpression 警告も見る）。
- [ ] 開始・停止ボタン: 連打しても二重に開始・停止しない。押している間は押せず、完了後に文字（開始⇔停止）が正しく戻る。表示言語を切り替えても文字が崩れない。
- [ ] トレイのメニュー（開く・開始・停止・終了・プロファイル選択）と、ホットキー・スワイプによるプロファイル切替。
- [ ] 最小化・復帰（タスクバー、トレイ）。位置・大きさ・列幅が、再起動後に戻る。
- [ ] プロファイル一覧: 新規・編集・削除・名前の変更・複製・取り込み・書き出し。何も選んでいないときは、編集・削除・名前の変更・複製・書き出しが押せない。ダブルクリックで編集。複製の名前の入力バーが出入りする。
- [ ] 機器ごとの「編集」「新しいプロファイル」（スロットの番号が正しい機器へ効く）。
- [ ] 設定タブ: OSC の受信・送信、UDP サーバー（入れる・切る）、スワイプ、「起動時に実行」の詳細の出入り、ログの書き出し・消去、ログ一覧のダブルクリックで全文表示、ドライバーの導入（導入のあとにドライバーの状態の表示が更新される）、プロセスの優先度（管理者でなく RealTime を選ぶと High へ戻って通知される）。
- [ ] 更新の確認・バージョン情報（リンクがブラウザーで開く。12 件）・変更履歴・機器の登録の設定画面。
- [ ] 自動プロファイル: プログラムの追加（Steam・スタートメニュー・フォルダー・実行ファイル）の間、画面が操作できず、終わると一覧が戻る。追加したあとは該当メニューが消え、「チェックのないものを隠す」で戻る。削除・保存・上へ・下へ。診断ログのチェック。
- [ ] 割り当て編集（スペシャルアクション）: マクロの記録、マルチタップの記録（タップ・長押し・ダブルタップ）、起動するプログラムの参照。保存・取り消し・電池の色・出力ピッカーは従来どおり。
- 疑う場所: `DS4Windows/UI/MainWindow.xaml` の `Command="{Binding …}"`（設定タブの中の要素は `DataContext.…` ＋ `RelativeSource` で結ぶ）。`CommandGuard` が失敗をログ（Error）へ出す。
