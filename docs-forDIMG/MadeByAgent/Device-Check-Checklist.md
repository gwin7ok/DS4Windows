## 9h. null のときの動きを変えた箇所（PhaseRV9）
以前は例外（`NullReferenceException`）になりえた箇所を、何もしない・空として扱う形にした。通常の操作では null にならないため、「これまでと同じに動く」ことの確認が中心。台帳は `PhaseRV9-Guards.md`。

- コントローラー一覧: 接続・切断・再接続を繰り返しても、一覧が空の瞬間に落ちない。
- メイン画面: コントローラーの状態アイコンの右クリック、ID 列のツールチップ、ライトバー色のボタン（右クリックのメニュー）が、これまでどおり出る。

- 割り当て編集（BindingWindow）: 開く・ホバー・振動テスト・ライトバー色の選択・マクロ記録（記録→保存、取り消し）。

## 9k. ジャイロ・タッチパッドの状態の整理（PhaseRV13）
トリガー判定の値渡し、入力の引数渡し、ジャイロ 3 モードの分離、タッチパッドの前回値の窓口化、スティックの状態のデバイスごとの型を行った。**挙動の変更が 1 件ある**（次の最初の項目）。1 項目ずつ確認する。
- **MouseJoystick の Y の初期化（挙動の変更）**: ジャイロの出力モードを MouseJoystick にし、トリガーで出力が止まっている間（または軸が出力されない設定）、Y 軸が中立（128）へ戻ること（旧は X だけが戻り、Y が前の値のまま残っていた）。
- ジャイロ（Controls・Mouse・MouseJoystick）: トリガー（OR／AND、トグル、逆ラチェット）、感度、スムージング（1 ユーロ）。
- タッチパッド: スワイプ（4 方向）、スライドによるプロファイル切り替え、タップ、クリック領域（左・右・上・複数指）、トラックボール、タッチスティック。
- スティックの出力の重ね合わせ（フリックスティック、2 段階トリガー、デルタ加速）がデバイスごとに独立して動くこと（複数台がある場合）。

## 9l. 入力機器の部品化（PhaseRV14）
- Switch Pro（USB・Bluetooth）: 接続して動作する（初期化のサブコマンド、スティックの較正、プレイヤー LED の点灯）。切断（トレイ・スタートメニュー）でジャイロ・振動が止まり、再接続できる。ホーム LED の設定の切り替え。
- DualSense（USB・Bluetooth）: ライトバーの色、プレイヤー LED（スロットの点灯、電池残量の表示）、ミュート LED（Off・On・Pulse）、振動、トリガーの効果。Bluetooth で出力が受け付けられる（CRC）。
- DS4（USB・Bluetooth）: ライトバー・振動。USB・Bluetooth の出力レポートの違い。
- 全機種: 振動の自動停止（設定した時間で止まる）、振動中に出力が途切れない（4 秒ごとの送り直し）、無操作での切断（Bluetooth）。

## 9m. 画面の出し分けの移行（PhaseRV19。見た目が変わっていないことを見る）
- 出力ピッカー（BindingWindow）: 割り当て編集画面の Press Key（Controls）で開くと、Default／Unbound と Extras が出る。スペシャルアクションの Press Key で開くと、Default／Unbound は出ず、Extras は出る。Record A Macro・Toggle・Scan Code は、どちらにも出ない。
- 割り当て編集画面（AssignmentEditor）: Controls のモードでは種別の一覧の先頭（「種別を選んでください」）が出ず、Default／Unbound が出る。スペシャルアクションのモードでは逆。保存できない種別が選べない（灰色）。
- マクロ記録（RecordBox）: 記録を始めると、一覧・保存・キャンセル・プリセット・待機の追加などが使えなくなり、記録を止めると戻る。
- 出力ピッカーでマクロ記録を開くと、割り当てのパネルと Extras が隠れ、閉じると戻る。
- 画面の図（プロファイル編集）: コントローラーの図のボタンに文字が出ない（割り当ては図の下のラベルに出る）。

## 9n. 設定パネル・導入ダイアログの移行（PhaseRV20。見た目が変わっていないことを見る）
- はじめの案内（WelcomeDialog）: 導入ボタンを押している間、ViGEm・HidHide・FakerInput の操作がすべて使えなくなり、終わると戻る。OS の条件で使えない項目（HidHide は Windows 10 x64 未満、FakerInput は Windows 8.1 未満）は、終わっても使えないまま。
- ライトバー設定: 「バッテリー残量で色を変える」を入れると「空の色」の枠が出て、切ると隠れる。プロファイルを切り替えても、枠の表示がそのプロファイルの設定に合う。虹色のボタンを押すと色の枠が操作できなくなり、もう一度押すと戻る。
- 言語パック（設定タブ）: 一覧の取得が終わるまで言語の一覧は選べない。選択を変えると「適用」が押せ、適用すると押せなくなる。
- 設定タブ: プロセスの優先度の一覧（4 項目。順序は保存値の添字）、ログの最小レベルの一覧（Trace〜Fatal）が表示され、保存した値が選ばれている。
- 自動プロファイル: プログラムを選ばない状態で、各コントローラーの選択が「(none)」へ戻る。
