S9 の再確認で、次の追加の要望・課題も対応した（すべて実機で確認）。
- 削除済みのプロファイルを参照する Load Profile を、Controls／SA タブの一覧で「(none)」と表示する（S9-10）。
- 複製ダイアログの入力欄の初期値を、複製元の名前にする（S9-14）。
- マクロの記録画面のボタン名を、Emulated Controller に合わせる（DS4 は Cross／Circle／L1／PS など。S9-15）。
- Controls タブのコントローラー図のマウスオーバーによる一覧の選択の切り替えを、500ms 遅らせる。遅延中にクリックしても、クリックしたボタンを開く（S9-16）。
- 自動プロファイルから元のプロファイルへ戻す通知の電池残量を、「N/A」固定でなく実際の値にする（S9-5 の追加分）。
- Controllers タブの電池表示を、60 秒ごとに読み直す（変化通知の取りこぼしで表示が古い値のまま止まっていた。S9-17。**時間経過の実機確認が残る**）。

## 4. 機能の変更・廃止（ユーザー承認済み）

| 項目 | 内容 |
|---|---|
| **Debouncing の廃止（機能廃止）** | `Debouncer` とフィルター、`DebouncingMs` の設定・保存・UI を削除。古いプロファイルの `<DebouncingMs>` は読み捨て、保存しない。タイミング計算の `+ DebouncingMs` の項は取り除いた（値 0 と同じ動き）。**GitHub Issue は作らない**（ユーザー判断、2026-11-03）。規約 §2.2 の例外（ユーザーが明示的に承認した機能廃止） |
| 「Enable Output data to DS4」 | Emulated Controller に関係なく働く。ON でも出力を DS4 に強制しない。ON→OFF のとき消灯を 1 度書く。表示名を「物理コントローラーへ出力データを送る」に変更し、説明文を更新。W4 の補正 (c) は廃止 |
| 切断時の一時プロファイルの扱い | 切断したら、一時プロファイルの状態を維持しない（再接続では通常のルールで決まり、その後の再照合が自動プロファイルを適用する）。台帳 P9E6a-4 の期待値はこの仕様に読み替える |
