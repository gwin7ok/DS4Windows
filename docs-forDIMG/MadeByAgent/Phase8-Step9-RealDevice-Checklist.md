- **★** = 最低限実行する（これだけで、Step8 の削除が実機で壊れていないことの主な根拠になる）。合計 **18 項目**。

## 進め方・記録

- 順序: P1〜P4 → A-1〜A-5 → B → C → ログ → A-8（切断）→ A-9（再接続）。
- 結果は「○／△／×／未／不能」で、この表の「結果」の列に書く（元のチェックリストの U-35〜U-49 の「結果」も、同じ内容に更新する）。
- ×が出たら、現象とログの該当行を貼る。ロールバックは git（該当 PR の revert）で行うため、どの項目が×かで、戻す PR（8-0／8a／8b／8c／8d）を決める。対応は目安: B・C-1/2 ← 8a、A・U-49 ← 8b、起動・DI ← 8c／8d、C-3/4 ← 8-0。
- 最低限（★）が全部○なら、Step9 は合格として Phase9 へ進める判断材料になる。機材がない（機材）の項目は、「確認不能」として記録し、Phase8 の完了条件にするかをユーザーが決める。
