# PhaseRV8 コメント整理の規則（案。ユーザーの承認待ち）

作成日: 2026-11-20

## 分類
| 記号 | 内容 | 扱い |
|---|---|---|
| a | 設計意図・理由・制約（スレッド、循環、呼ばれる時点、順序、互換性） | **残す** |
| b | 原則4 の TODO／FIXME／HACK | **残す**（件数を前後で一致させる） |
| c | Phase／Step の参照（例: `Phase8-Step4b W6`） | 参照だけを外す。外して意味が通らないときは、意味が通る形へ書き直す |
| d | 旧実装の説明・削除の記録（「旧: …」「…を削除した」） | 外す。ただし、今の制約を説明する部分（なぜ今の形か）は、現在形で残す |
| e | 長すぎて意図が埋もれたコメント（連続する `//`・`///` が **12 行以上**） | 意図だけに要約する。(a)(b) の内容は落とさない |

## 手順
1. `Find-HistoryComments.py <フォルダー>` で候補を出す（読むだけ）。
2. 目で確認し、ファイルのまとまりごとに手で直す。**一括の自動置換はしない。**
3. コミットごとに `Verify-CommentOnlyChange.py --base HEAD~1 --head HEAD`（直前との比較）が「違い 0」になること。
4. 要約（e）した分は、旧→新の対応表を `PhaseRV8-Summaries-<層>.md` に残す。ユーザーが各層 **20 件**を抜き取りで確認する。
5. 層ごとにビルドと `--filter "Category!=Slow&Category!=Benchmark"`。最後に Debug ALL。
6. 前後で `keep`（TODO 等）の件数が同じこと。
