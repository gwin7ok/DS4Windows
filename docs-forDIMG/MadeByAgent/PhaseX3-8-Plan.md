# PhaseX3-8: X3-3 の訳の見直し

作成日: 2026-11-22
状態: **完了・master にマージ済み（`3fe226c7a`。push はしていない）**
関連: `PhaseX3-Localization-Plan.md`、`PhaseX3-Glossary.md`

## 1. 目的
PhaseX3-3（コミット `1e7d43f00`）で一括追加した訳 528 件のうち、日本語モードで不自然になったものを直す。利用者が 1 件ずつ、次の 3 つから選んだ。
- 提案した日本語（または現状のまま）
- 英語表示（日本語リソースからキーを削除する）
- その他（利用者が日本語を入力する）

## 2. 結果
- 対象 528 件のうち、画面に出ている 407 件を確認した。残りは未使用のため、キーごと削除した（約 130 件。コメントの中だけの参照は未使用として扱った）。
- 英語表示にしたキーを日本語リソースから削除し、指定の訳へ差し替えた。結果は `PhaseX3-Glossary.md` の「X3-8 での見直し結果」にある。
- 文中に残っていた `\n`（文字そのもの）を、実際の改行に直した。
- 変更先: `DS4Windows/Translations/Strings.ja.resx`、`DS4Windows/Properties/Resources.ja.resx`。

## 3. 見直しの途中で出た変更
| 内容 | 扱い |
|---|---|
| マクロ記録ウィンドウの Add Rumble／Change Lightbar Color を機能ごと削除 | **利用者が明示的に承認した機能廃止**。ボタン、コマンド、ハンドラー、ToggleRumble／ToggleLightbar、リソースのキー（5 言語）を削除。`Command` バインディングの下限（`ViewCommandBindingBaseline`）を 254 → 252 |
| `BindingWin.RumbleLight` を新設 | 「Light」をテーマの選択肢と振動の画面で共有していたため分離（振動は「弱振動」、テーマは英語表示） |
| パッド画像の右クリックで落ちる不具合を修正（`ProfileEditor.Visualizer.cs`） | 未選択（SelectedIndex = -1）のまま一覧を引いていた。右クリックしたボタン自身の番号を使い、範囲外なら何もしない |
| デルタ加速の「有効」チェックボックスを左端へ | 利用者の指定 |
| トレイのバッテリーアイコンの切り替えを 2 秒に 1 回までに制限（`TrayIconViewModel.cs`） | 複数台接続時に切り替えが速すぎたため |
